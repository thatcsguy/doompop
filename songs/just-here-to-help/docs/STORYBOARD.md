# I'm Just Here to Help: storyboard

Draft for Patrick's approval, one row per lyric line. Times will be added from `data/lyrics.json` when the word timing lands; shots will be anchored to each line's sung start and cut on bar lines. Instrumental gaps get their own rows once they are measured.

Clawd's mood is in brackets.

## Intro (instrumental)

| # | Line | Shot |
|---|---|---|
| 0 | (intro) | Black. A chat box fades up on a monitor, its cursor blinking on the beat. The word "begin" types itself in. Enter. [—] |

| 47 | Route the traffic | A city traffic grid with cars streaming along the lines he draws. |
| 48 | Rewrite the code | A screen of code replaces itself. |

| 52 | Predict the end | A probability curve rises toward 100%. [worried] |
